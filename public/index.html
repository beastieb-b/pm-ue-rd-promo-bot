How It Works

1
Source Scan — Checks the monthly Reddit threads plus selected public-code sources, then scores each candidate based on freshness, community signals, and whether it looks reusable for existing users.
2
Code Applier — Navigates to Postmates in a background Chrome window, types each code, and records the result. Max 5 codes per run with 2-minute gaps to avoid rate limiting.
3
Status Tracking — The dashboard keeps source health, confidence, recent verification hints, queue state, and apply results in one place so it is easier to see what is worth trying next.
4
Monthly Reset — When a new monthly Reddit thread is detected, the queue and results archive/reset for the new month while the source catalog keeps monitoring metadata around.
